# bertucci.dev

Carmen Bertucci's personal site. Built on Jekyll, deployable to GitHub Pages.

## Structure

- `index.html` — home
- `about.md` — about
- `projects/` — projects
- `blog/` — writing
- `contact.md` — contact
- `assets/` — css / js / icons / img
- `_layouts/`, `_includes/` — Jekyll templates
