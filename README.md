# bertucci.dev

Carmen Bertucci's personal site. Built on Jekyll, deployable to GitHub Pages.

## Structure

- `index.html` — home
- `about.md` — about (anchored by a tattoo icon)
- `projects/` — projects (ClearPing, AI Deck series, DGX Spark DeepSeek runner)
- `blog/` — writing
- `contact.md` — contact
- `assets/` — css / js / icons / img
- `_layouts/`, `_includes/` — Jekyll templates

## Design layer (pending)

Icon system will be built from Carmen's tattoos, stylized into a consistent
monochrome line-art SVG set. Source art and photos land in the workspace
`tattoos/` folder; finished SVGs go to `assets/icons/`. The unified style
is what makes 20 different designs read as one deliberate set.
