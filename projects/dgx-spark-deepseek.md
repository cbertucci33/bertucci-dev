## DGX Spark DeepSeek Runner

A vLLM runner for DeepSeek V4 — an abliterated vision variant — on an NVIDIA
DGX Spark / GB10 system.

**Status:** Active

### What it is

Getting a frontier-class model running well on local Blackwell hardware.
This is the ongoing work of running DeepSeek on the DGX Spark and making
it fast and reliable enough to actually use.

### Why

Local frontier hardware deserves a real, working model stack. This project
is about closing the gap between "the box is big" and "the box is useful."

### Details

- Live in the `dgx-spark-vllm-deepseek-v4-vision` repo
- Public, with the runner setup documented
- More as the work progresses
